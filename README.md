# Ugay's Elegant Stitches — Tailoring & Rental Management System

A web-based management system for tailoring and garment rental shops. Built with PHP, MySQL/MariaDB, and Apache.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/vistalreyan-byte/ugays_elegant_stitches)

---

## Features
- **Authentication & Security**: Role-based login and session protection.
- **Interactive Dashboard**: Live metrics, recent tailoring orders, upcoming appointments, and inventory stock highlights.
- **Customer Management**: Full customer directory (Add, Edit, Delete, Search).
- **Tailoring Orders**: Order tracking from Pending to Completed with target due dates.
- **Rental Management**: Garment rentals, due date tracking, and 1-click return workflow.
- **Rental Inventory**: Stock management for gowns, suits, barongs, and accessories.
- **Appointment Scheduling**: Fitting, measurement, and consultation bookings.
- **Billing & Payments**: Payment transactions recorded with Cash, GCash, Bank Transfer, and Card tracking.
- **Business Reports**: Analytics summaries, payment channel breakdowns, and printable reports.
